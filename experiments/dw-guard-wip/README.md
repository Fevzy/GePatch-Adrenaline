# Незавершённый guard-band WIP

Снимок `main.c` и двух test-файлов из рабочего каталога на 2026-10-30.
Общие helper-файлы находятся в основном каталоге `gepatch`.
Основная ветка собирает рабочую baseline с отключённым guard.

Эксперимент включает CPU clipping крупных треугольников и дополнительный CALL
только при глубине не более одного игрового CALL. Крупные таблицы вынесены
из kernel BSS в upper RAM. Host: 17 PASS; ослабление depth guard ломает тест.

Debug SHA256:
`7a032f0f5f3bd6a99cf4b384e6bb20173de20b395d7ab5766c3fded026be1ca7`.
Пользователь сообщил **чёрный экран в Dynasty Warriors**. В выделенном логе
текущего запуска `cut=0`; причина регрессии не установлена.
Эксперимент снят с Vita, baseline восстановлена. Не включать в релиз.

Следующая работа: найти причину регрессии до попыток разрезания, проверить
достижимость CALL/BASE и глубину draw, сократить стоимость CPU check.
Альтернатива CALL — перенаправление собственных BASE/VADDR/VTYPE/PRIM draw
на вершины пула с учётом серий 6-вершинных strips, продолжающих VADDR.
